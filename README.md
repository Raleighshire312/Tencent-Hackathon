# IntentLock: Proof-Carrying Payments

Tencent Cloud Singapore 2026 DBS Banking Track MVP.

This workspace is intentionally self-contained. The first implementation target is a local, offline-safe mock payment flow in which AI may propose a structured intent, while deterministic validation and explicit approval control execution.

## Current status

- Milestone 1: workspace discovery and project inventory complete.
- Milestone 2: deterministic mock payment core: pending.
- Tencent credentials: not configured.
- Real transfers: not supported; all transactions will be simulated.

## Safety boundary

No real banking credentials, payment credentials, or private Tencent keys belong in this directory. Use `.env` locally when integration begins and keep only redacted examples and screenshots in project materials.
